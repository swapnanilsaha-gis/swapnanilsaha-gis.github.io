# Swapnanil Saha · GIS Portfolio

Personal portfolio of **Swapnanil Saha**, Geospatial Analyst (GeoAI, Remote Sensing, Web GIS) and M.Sc. Geoinformatics student at Symbiosis Institute of Geoinformatics, Pune.

## What's on the site

| Project | Highlights | Live dashboard |

The site also includes skills, education, certificates and a downloadable CV.

## Built with

A single static HTML page with hand-written CSS and vanilla JavaScript: no framework and no build step. Fonts are Archivo, Source Serif 4 and JetBrains Mono. Charts are inline SVG drawn to scale. It's hosted on GitHub Pages.
